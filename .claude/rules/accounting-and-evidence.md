# Accounting and evidence

Money is integer micro-USD. Ledger events are append-only and idempotent. Reserve organization and account capacity transactionally before provider work, including background model jobs and timed audio streams. Unknown outcomes retain conservative liability until reconciliation. Never trust a client's balance, duration or price.

A task is done only when its acceptance passes and the evidence log states what was actually run. Tests using mocked providers are labeled mocked. Receiver-side screen-share evidence requires an actual receiver. Signing requires a verified signed artifact, not merely configuration files. If blocked, leave the checkbox open and continue independent tasks.
